# LegalHub: AI-Powered Legal Assistance Platform

## 🌟 Project Overview
LegalHub is an AI/LLM/RAG/Agent-based system designed to bridge the gap between citizens seeking legal guidance and legal professionals.

## 🛠️ Technology Stack
* **Backend:** Python (FastAPI/Django)
* **AI/Data:** LLM/RAG, Vector Embeddings
* **Frontend:** React/Next.js

## 🗺️ Project Phase
The team is currently in the **Requirements Analysis** phase (Nov 4 - Nov 13) and preparing for **Development Prep** (Nov 14 - Nov 24).
